# HR-Analytics-Dashboard-PowerBI
HR Analytics Dashboard built using Power BI
🔹 Project Overview

This project is an HR Analytics Dashboard created using Power BI to analyze employee data and provide actionable insights for HR decision-making.

The dashboard helps understand workforce distribution, salary trends, employee growth, and demographic analysis.

🔹 Key Features

Total Employees, Average Salary, Min & Max Salary KPIs

Employee distribution by Gender

Employees by Job Title

Salary analysis by Education Qualification

Cumulative Headcount Growth over time

Interactive slicers for Gender and Job Title

🔹 Tools & Technologies

Power BI Desktop

DAX (Data Analysis Expressions)

Excel (Data Source)

🔹 KPIs Used

Total Employees

Average Salary

Average Age

Average Leave Balance

Minimum & Maximum Salary
